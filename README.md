2D Shooter Game

A 2D multiplayer shooter inspired by Counter-Strike 2 (CS2). The game features fast-paced combat, competitive gameplay, and multiple game modes.

Game Modes
Uplink: A team-based game mode focused on completing objectives and working together.
Deathmatch: A fast-paced free-for-all mode where players compete to get the most eliminations.
